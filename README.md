# EvolvingDomains 0.1

**A minimal Julia package for solving PDEs on moving domains.**

Mini package designed to provide a set of utilities to write moving domain problems in the gridap ecosystem. It leverages `GridapEmbedded`.

Features : 

EvolvingDiscreteGeometry object to facilitate the definition of Evolving Geometries in GridapEmbedded.
WENO5 time stepping for level set evolution.
Conservative Cell Integrated Semi Lagrangian scheme for advection in Evolving Geometries.
